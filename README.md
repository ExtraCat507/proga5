# Менеджер коллекции  
**Лабораторная работа №8, 2 семестр 2025 года**

Клиент-серверное приложение для управления коллекцией объектов. Проект реализует многопоточную обработку запросов от нескольких пользователей, безопасное хранение данных в реляционной БД и интерактивный графический интерфейс.

## 📂 Структура проекта

* **`client`** — графический интерфейс, локализация (i18n), валидация ввода и сетевое взаимодействие с сервером.
* **`server`** — аутентификация, многопоточная обработка подключений, бизнес-логика и взаимодействие с базой данных.
* **`common`** — общие классы (сущности, DTO), используемые для передачи данных по сети.

## 🛠 Стек технологий

* **Язык:** Java 17
* **GUI:** JavaFX (FXML)
* **База данных:** PostgreSQL + JDBC
* **Сеть:** TCP-сокеты (Java NIO)
* **Многопоточность:** `ForkJoinPool`, `FixedThreadPool`
* **Безопасность:** Хеширование паролей с солью и перцем (SHA-384)

## 🧩 Паттерны проектирования

* **MVC (Model-View-Controller)** — разделение визуального представления, состояния и контроллеров в клиентском приложении.
* **Command** — инкапсуляция клиентских запросов в объекты Command для удобной передачи по сети и обработки.
* **DAO** — абстракция логики взаимодействия с базой данных.
* **Singleton** — управление уникальными ресурсами (менеджер БД, локализация).
* **Observer** — автоматическое реактивное обновление интерфейса (таблицы и визуального холста) при изменении коллекции.

## ➡️ Запуск

* Запустить PostgreSQL на порту 5432 и создать новую базу данных
* Собрать проект ` .\gradlew build `
* Запустить клиентский и серверный модули  
` java -jar .\Server\build\libs\Server-1.0-SNAPSHOT.jar `  
` java -jar .\Client\build\libs\Client-1.0-SNAPSHOT.jar `
